# Odmęt

Gra przeglądarkowa na telefon: prowadzisz kolejne drużyny z portowego miasta Odmęt na wyprawy za mury. Bohaterowie giną, miasto pamięta.

- `index.html` — cała gra w jednym pliku (bez bibliotek, bez zewnętrznych zasobów). Otwórz w Chrome na telefonie.
- `CEL.md` — cel projektu, skala docelowa, zakazy, etapy. Czytać na starcie każdej sesji.
- `tools/sim.js` — symulator: `node tools/sim.js 400 1 smart` gra 400 wypraw bez przeglądarki i wykrywa błędy, zawieszenia i statystyki balansu.
